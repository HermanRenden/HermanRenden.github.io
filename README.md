# hermanrenden.github.io

Personal site for Herman Renden — web programming student, service-industry veteran, hockey fan.

Live: https://hermanrenden.github.io

## What's here
- `index.html` — the main portfolio page (hero, about, experience, skills, contact).
- `rink.html` — "The Rink," a hand-built canvas hockey shootout mini-game.
- `assets/css/style.css` — all styling.
- `assets/js/main.js` — cursor, scroll progress, aurora canvas, reveal animations, nav, Konami-code easter egg.
- `assets/js/rink.js` — the shootout game.
- `assets/CV-Herman-Renden-2026.docx` — downloadable CV.

## Stack
Plain HTML, CSS, and JavaScript. No build step, no frameworks, no dependencies. Served straight from GitHub Pages.

## Dev
Open `index.html` in a browser, or serve the folder with anything static — `python -m http.server`, `npx serve`, or the VS Code Live Server extension.
